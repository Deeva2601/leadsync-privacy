LeadSync Demo Privacy Policy

Last updated: October 23, 2026

Purpose

LeadSync is a demonstration project created to test the integration of Meta Lead Ads with a React Native application.

Information We Collect

During testing, the form may collect a name, email address, and phone number submitted by the user.

How Information Is Used

Information is used only to test the demo integration, verify lead delivery, and display lead details in the application.

Data Sharing and Storage

This demo does not intend to sell personal information. Test data may pass through the backend server for integration testing. Please use test details only.

Data Deletion

If you submitted information and want it deleted, contact the project owner through the GitHub repository linked below.
